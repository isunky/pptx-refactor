# Security Policy / 安全策略

## Supported versions

Only the latest published release receives security fixes.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting or a private Security Advisory for security-sensitive reports. Do not disclose an unpatched vulnerability in a public issue.

For ordinary bugs, use the public issue tracker with a fully synthetic reproduction.

## Presentation privacy

PowerPoint decks may contain personal information, customer data, hidden slides, comments, speaker notes, document properties, embedded files, or revision history. Never attach a confidential or third-party deck to a public issue. Remove sensitive content and metadata, or create a new synthetic deck that demonstrates the same behavior.

请勿在公开 Issue 中上传真实客户 PPT、内部演示文稿或含有个人信息的文件。请清除敏感内容和元数据，或使用全新合成文件复现问题。
